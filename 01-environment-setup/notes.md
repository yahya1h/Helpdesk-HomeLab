Objective: Install a hypervisor and build the first VM for the helpdesk lab.

## Steps
1. Installed Oracle VirtualBox as the hypervisor.
2. Downloaded the Windows 11 ISO (VM not yet created).
3. Installed Windows Server 2025 as a VM.

## Tools / tech used
- Oracle VirtualBox [version]
- Windows Server 2025 [edition]
- Windows 11 ISO [version]

## What I learned
- A hypervisor lets one physical machine run several isolated virtual
  machines, so I can build and break a full Windows environment without
  touching my main laptop.
